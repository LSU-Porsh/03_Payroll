# Simple Payroll Website

This project simulates a basic payroll calculator.

## Features
- Input employee name, hours worked, and rate per hour
- Calculate total pay

## Contribution Workflow
1. Claim an Issue from the Project board.
2. Create a branch and make your changes.
3. Open a Pull Request linked to the Issue.
4. Once merged, the Issue will close automatically.
